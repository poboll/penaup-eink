# Recovered Web Themes

These styles are retained as rollback material from the former FrameFilm web tool. They are not loaded by the Penaup workbench and are not part of the product design system.

The active workbench uses `apps/web/css/style.css` and the local `style_penaup_contrast.css` mode. Remote font imports were removed so the recovered files do not create hidden network dependencies.

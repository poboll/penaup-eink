03 / 网络

把 Wi-Fi 留在设备里。

所有设置通过当前 BLE 连接写入设备。密码不会写入浏览器日志；清除网络后，页面会把状态标记为待确认，直到重新回读。

NETWORK CONFIG未连接
WHY BLE FIRST

先修好连接，再谈云端。

网络清除使用已核实的 `0x3B`，不会把照片或密码发到服务器。设备连上 Wi-Fi 后，仍可回到工作台创作。

此操作会断开 Wi-Fi，但不会恢复其他设备参数。

04 / 维护

需要重启，还是重新开始？

重启和恢复出厂都会让设备离开当前连接。发送命令之后，页面只会显示“等待重新广播 / 状态待确认”，重新连接并成功读回状态后才会结束。

REBOOT / 0x24

只重启设备

保留照片、网络和显示设置，适合设备暂时没有响应时使用。

FACTORY RESET / 0x22

恢复出厂设置

会清除设备参数并重启。照片文件是否保留取决于当前固件实现，请先确认备份。

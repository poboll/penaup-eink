# 花生片类纸表面与 3.68 英寸竖版画布收口设计

> Copyright (c) 2026 poboll · `LicenseRef-Poboll-NonCommercial`

## 目标

本轮把 `m8mi6m.top` 可观察到的纸面语言转译为 Penaup 自有的界面规范：接近白色的灰白草纸、低对比纤维、细黑线、轻微纸片错位阴影和不完全对称的小圆角。页面仍保留花生片的墨黑、六色显影和汇文明朝体，不复制参考站的代码、素材或内容。

核心颜色从 `#F8F8F4` 提亮到 `#FAFAF7`，预览底从 `#F2F2EE` 提亮到 `#F4F4F0`。噪点只保留一层低透明度 CSS grain；`prefers-reduced-motion` 时停止噪点和扫描动画。

## 画布契约

Pro 是当前默认产品：用户看到的视觉相纸固定为 `528 × 792`，即 3.68 英寸竖向比例 `2:3`。STD 使用 `400 × 600`，Max 使用 `1200 × 1600`。Web 的创作 canvas、相机、一言、转换器、模板和微信读书屏保都使用对应 Profile 的 `canvasWidth/canvasHeight`。

历史 `.film` 文件仍使用 Pro `792 × 528` 头部与像素布局。端侧量化后通过 `film-core.canvasPixelIndex()` 做视觉坐标到协议坐标的转换；不修改固件宏、BLE 分块、颜色索引或文件头。

## 控件与响应式

- 主要操作统一最小高度 `48px`，移动端连续操作使用 `54px`；图标重置操作保持 `44px`；
- 主按钮是墨黑纸片，次按钮是接近白色纸片，均使用细边框、轻微右下错位阴影和按下回落；
- 创作方式 tab 四列等宽，操作行在 `720px` 以下改为单列；长文案不再压缩按钮高度；
- 视觉相纸在工作台内以 `64dvh` 为桌面上限，在窄屏以 `58dvh` 为上限，保持竖版比例并避免预览遮住底部导航；
- 标题使用汇文明朝体，技术尺寸和状态使用等宽字体，关键帮助正文不低于 `14px`。

## 验收

- 8787 首页、工作台、设备工具共享同一套浅草纸 token；
- Pro 默认四个编辑 canvas 与读书 canvas 都声明并运行在 `528 × 792`；
- Node、Web、小程序契约测试通过；浏览器检查不出现横向溢出、控制台错误或按钮文字错位；
- 固件矩阵脚本的自动临时目录在成功、失败和 dry-run 后都可清理，显式构建根目录不被脚本删除。

## 设计判断

本轮把 `expert-eureka` 与 `m8mi6m.top` 作为视觉参考，而不是代码或素材来源。两者可观察到的共同语言是：接近白色的纸面、细黑线、编辑部式编号、纸片叠放关系和短而克制的阴影。Penaup 采用更轻的灰白草纸版本，纹理由 CSS 的低频噪声、纤维方向和局部高光组成，不新增远程图片请求，也不把纹理铺到文字表面形成噪声。

## 纸面 token

| Token | 值 | 用途 |
| --- | --- | --- |
| `--penaup-paper-base` | `#fcfcf9` | 全站底色，接近白但不刺眼 |
| `--penaup-paper-white` | `#fffffc` | 抬起的纸片、按钮和导航面 |
| `--penaup-paper-rice` | `#f5f5f0` | 相纸、工作台内层和空状态 |
| `--penaup-paper-ink` | `#20211f` | 标题、主要按钮、关键线条 |
| `--penaup-paper-blue` | `#4d73ad` | 当前步骤、辅助信息、链接 |
| `--penaup-paper-yellow` | `#c49a24` | 显影扫描、纸胶带和强调 |

纸片使用 1px keyline、2–5px 的实体右下偏移和 0–8px 的柔和阴影。圆角只用于保护触控和内容边界，不使用大面积圆形光晕或玻璃拟态。移动端把纸片堆叠收成单层，避免装饰物挤占 3.68 英寸竖向相纸。

## 首页构图

Hero 产品图后不再出现大圆环。底层是略微逆时针旋转的草纸板，中层是细登记线和六色校样条，产品照片作为第三层纸片固定在中间，右上角保留一张小的 `6 → 48` 规格签。登记线和裁切标记采用 CSS 绘制，产品图仍是唯一的视觉焦点。

首页标题和正文继续使用原有 `Huiwen Mincho`/宋体展示组合；任何创作字体选择只能作用于读书屏保或文字卡片的 Canvas 排版。字体选择的状态通过 `aria-pressed` 表达，切换后保留数据并重新显影。

## 48 色显影样本票

实验室是 6 行 × 8 列：行是黑、白、红、黄、蓝、绿六种物理基色，列是从浅到深的 8 档显影层级。每个色票使用矩形纸样、细边和轻微网点纹理；列标签说明层级，行标签说明基色。叠色、网点、抖动只改变色票内的标记方式，不改变六行的物理含义。

说明文案明确“最多 48 种色彩观感”，并补充这不是新增 42 种独立墨水；`.film` 仍然只保存六色基础索引，最终观感取决于渲染算法与面板。实验室支持按钮选择、键盘焦点、自动轮播和 Reduced Motion。

## 工作台边界与验收

工作台的连续路径保持为“选择/取回 → 排版 → 显影 → 下载或发送”。上传、相机、一言和读书四个 Tab 使用同一套按钮高度、焦点样式、错误状态和 528 × 792 视觉相纸；内部兼容 `.film` 仍为 792 × 528，BLE 分块和颜色编码不动。

微信读书在开始显影前提供汇文明朝体与系统宋体选择，并在状态文案中说明“只影响本张屏保”。真实 Key 不进 URL、localStorage、日志或数据库；示例数据可离线展示完整流程。移动端要求无横向溢出、主要操作不低于 48px、图标按钮不低于 44px，失败保留预览并给出可重试动作。

# 花生片 Penaup 类纸表面

> Copyright (c) 2026 poboll · `LicenseRef-Poboll-NonCommercial`

花生片的网页背景采用接近白色的灰白草纸，而不是压暗的灰麻色。它只负责承接内容，不抢走标题、六色显影和设备预览的注意力；卡片与按钮像被剪下、轻轻压在纸面上的小纸片。

## 视觉规则

- 页面底色以接近白色的 `#F8F8F4` 为中心，顶部使用 `#FFFEFA` 的纸面高光，预览底/纸影落到很浅的 `#F2F2EE`；
- 纹理由低对比的斜向纸纤维和 CSS 噪点组成，不使用高对比横纵网格，不加载外部图片、不依赖第三方纹理包；参考页的灰感被压浅，保持接近白纸的阅读亮度；
- 纸面纹理的透明度保持在低位，正文与按钮的对比度优先于“看起来像纸”；
- 相纸预览单独增加细纤维层，显影扫描线只在生成/显影期间出现；
- 六色只作为小面积提示色：墨黑、纸白、红、黄、蓝、绿；“最多 48 种色彩观感”来自叠色、网点和抖动，不表示有 48 种独立墨水；
- 汇文明朝体 Web 子集用于标题和屏保排版，技术信息使用等宽字体，正文使用系统无衬线字体。

## 跨页面 token

| Token | 值 | 用途 |
| --- | --- | --- |
| `--penaup-paper-white` | `#FFFEFA` | 纸面高光、主要卡片 |
| `--penaup-paper-ivory` | `#F8F8F4` | 页面主背景 |
| `--penaup-paper-rice` | `#F2F2EE` | 纸面阴影与预览底 |
| `--penaup-paper-shadow` | `#E9E9E4` | 纸片错位阴影 |
| `--penaup-paper-ink` | `#20211F` | 正文与主要操作 |
| `--penaup-paper-blue` | `#4D73AD` | 进行中、链接、状态 |
| `--penaup-paper-yellow` | `#C49A24` | 显影、提醒、重点 |

Web 的基础 token 真源是 `apps/web/css/paper-surface.css`，最后一公里几何收口在 `apps/web/css/penaup-paper-finish.css`；两者在故事页、工作台和设备工具上共同统一背景、焦点轮廓、标题字体、触控尺寸和相纸纹理。减少动态时关闭噪点和扫描动画。微信小程序对应真源是 `apps/wechat/miniprogram/styles/paper-surface.wxss`，由 `app.wxss` 全局引入；它使用同一组接近白色的灰白草纸与低对比噪点，不把模板页退回旧的灰麻色。

按钮采用白色纸片、细黑边和轻微错位阴影；主按钮使用墨黑印章色，次按钮保持近白纸片，主按钮、次按钮、设备工具入口和小程序模板卡统一使用不完全对称的 5–8px 圆角，按下时回落 2px，避免不同端出现“漂浮的圆胶囊”。

## 参考边界

视觉研究参考了 [Sodamax778/expert-eureka](https://github.com/Sodamax778/expert-eureka) 的浅纸面方向、[m8mi6m.top](https://m8mi6m.top/) 的纸片按钮与“阅读数据 → 固定模板 → 导出”的流程。Penaup 只吸收可泛化的产品语言，没有复制其代码、素材、纹理或依赖；上游项目许可证变化不能替代本仓库的版权与来源核验。

## 验收

- 360、390、768、1440px 页面不出现横向滚动；
- 主要按钮高度不小于 48px，移动端读书实验室操作按钮不小于 54px；
- `prefers-reduced-motion: reduce` 下不显示持续噪点和扫描动画；
- 视觉纹理不进入 `film-core` 的颜色协议，屏保仍固定使用六色索引。

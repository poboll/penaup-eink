# 花生片 Penaup 资源

这里保存产品展示图、硬件渲染图和不会泄露用户隐私的公共素材。

## 使用规则

- 资源必须能说明来源、许可或由 `poboll` 新制作；
- 不提交用户照片、外包交付中未确认可再分发的素材、私有二维码或凭证；
- 产品图优先用于文档和预览，不在代码中写死远程 CDN；
- 六色示意应与 `docs/film/film.md` 的编码保持一致。

## 当前首页素材

首页 Hero 使用 `pic/model/model1.png` 的机械拆解结构图。它表达的是设备由相纸、面板、主板和外壳共同组成，不把一张实物产品切图误作品牌主视觉；来源与再分发边界仍以 `docs/legal/provenance.md` 为准。

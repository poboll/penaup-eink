# Penaup 历史硬件交付

这里保存接管前收到的 CAD、EDA 面板工程、3D 打印模型和原理图 PDF。目录名已经从 `hardware/penaup/` 的活跃层移入 `legacy/`，但文件内部的历史品牌和文件名不做覆盖式改写，以保留可追溯性。

这些材料不是 `firmware/penaup/`、`packages/film-core/` 或生产 PCB 的源码真源，也不因目录移动自动获得 `poboll` 独占版权。具体来源、第三方许可和外包合同边界见 [`docs/legal/provenance.md`](../../../docs/legal/provenance.md)。

新硬件工作应先确认屏幕型号、BUSY/CS 时序、供电、机械公差和 EDA 工程权限，再在对应的 Penaup 设计目录中建立可复核的版本；不要直接覆盖这里的历史材料。
